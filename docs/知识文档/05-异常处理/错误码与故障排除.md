# 错误码与故障排除

## 响应识别原则

前端和测试都不要只看 HTTP 状态。

| 层面 | 表现 | 处理方式 |
| --- | --- | --- |
| 业务成功 | HTTP 200，`code=0` | 使用 `data` |
| 业务失败 | 通常 HTTP 200，`code` 非 0 | 展示 `message`，按业务码分支处理 |
| 未登录 | HTTP 401 或业务登录态码 | 跳登录 |
| 无权限 | HTTP 403 或业务码 403 | 提示无权限 |
| 旧接口停用 | 业务码 410 | 不应重试，改用新接口 |

## 常见业务码

| code | 常见含义 | 典型场景 |
| --- | --- | --- |
| 400 | 参数或业务校验失败 | 密码不一致、项目编号重复、时间顺序错误、类型不存在 |
| 403 | 业务权限失败 | 会员未启用、已过期、无附件下载权限、账号未分配业务类型 |
| 404 | 资源不存在或不可公开 | 招标不存在、资讯不存在、文件不存在 |
| 410 | 接口停用 | `/api/admin/users`、`/api/admin/permissions` |
| 500 | 服务内部错误 | 文件保存失败、读取 OSS 失败、缩略图保存失败 |

## 招标常见问题

| 现象 | 优先排查 |
| --- | --- |
| 后台新增招标失败：业务类型不存在 | 查 `/api/admin/business-types/options`，确认类型启用 |
| 发布时间保存失败 | 确认 `publishAt <= deadline` |
| 报名截止保存失败 | 确认 `signupDeadline <= deadline` |
| 项目编号已存在 | 查 `biz_tender.project_code` |
| 已发布招标不能编辑 | 先用发布权限改回 `DRAFT` |
| 游客列表只有 3 条 | 这是设计，游客用 `/latest` |
| 会员列表看不到某招标 | 查会员业务类型、招标业务类型、招标状态和 `publishAt` |
| 会员能看详情不能下载 | 查 `canDownloadFile`、业务类型匹配、附件归属、会员状态和过期时间 |

## 会员常见问题

| 现象 | 优先排查 |
| --- | --- |
| 注册后不能登录 | 注册默认 `DISABLED`，需后台启用 |
| 启用会员失败 | 需要业务类型和过期时间 |
| 登录提示账号已过期 | `expiresAt` 为空或早于当前时间 |
| 登录提示未分配可用业务类型 | 会员无业务类型，或绑定的类型被停用 |
| 首次登录后跳到账户设置 | `profileCompletionRequired=true`，是设计 |
| 删除后列表还有历史数据 | 当前查询只查未删除；如仍显示，查前端缓存或接口响应 |

## 资讯常见问题

| 现象 | 优先排查 |
| --- | --- |
| 门户看不到资讯 | 需要 `PUBLISHED` 且 `publishAt <= now` |
| 已发布资讯不能编辑 | 先下架为 `DRAFT` |
| 无法发布资讯 | 当前账号需要 `NEWS_PUBLISH_BUTTON` |
| 封面不显示 | 查 `coverFileId`、`/api/files/{fileId}/thumbnail`、文件是否存在 |

## 权限和菜单常见问题

| 现象 | 优先排查 |
| --- | --- |
| 登录后没有菜单 | 查用户角色、角色菜单、菜单 enabled/visible |
| 点击菜单 404 | 查 `sys_menu.route_path`、`component` 和前端路由 |
| 按钮不显示 | 查用户权限 code 是否包含对应按钮 |
| 接口 403 | 查 Controller `@PreAuthorize` 和角色菜单绑定 |
| 权限管理页面报 410 | 权限接口已停用，应使用菜单/按钮授权 |
| 旧用户接口报 410 | 旧用户接口有意停用，改用会员管理或管理员账号管理 |

## 文件常见问题

| 现象 | 优先排查 |
| --- | --- |
| 上传返回重复文件 | 内容哈希去重，是正常行为 |
| 缩略图是文件类型封面 | 非图片/PDF 或生成失败，查看 `thumbnailStatus` |
| 后台预览失败 | 查 `/api/admin/files/{fileId}/view` 权限和文件是否存在 |
| 门户附件下载 401 | 未登录或 token 无效 |
| 门户附件下载 403 | 无下载权限、业务类型不匹配、会员禁用/过期 |
| OSS 文件读取失败 | 查 bucket、endpoint、key prefix、凭证模式和历史对象路径 |

## 部署常见问题

| 现象 | 优先排查 |
| --- | --- |
| 后端启动失败，prod 数据库配置报错 | 禁止空用户名/密码、root 用户、root 密码 |
| Swagger 不通 | 查 `systemctl status`、8080 端口、Nginx 代理 |
| 前端路由刷新 404 | 查 Nginx history fallback 和生产 base `/ztbgl/`、`/ztbfb/` |
| 后端升级后仍跑旧版本 | 查 systemd `ExecStart` 是否指向新 jar |
| 空库没有 admin/菜单/角色 | 当前 `DataInitializer` 主启动不自动注册；需执行 `sql/mysql8/data-initializer.sql` 或明确注册初始化器 |
