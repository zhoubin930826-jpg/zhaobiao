# 配置部署与运维手册

## 本地后端启动

最低依赖：

- JDK 8。
- Maven。
- MySQL 8。
- `APP_JWT_SECRET` 至少 32 字符。

启动前先把 `APP_JWT_SECRET` 配置为至少 32 位随机字符串，然后运行：

```bash
mvn spring-boot:run
```

默认地址：

- API：`http://localhost:8080`
- Swagger UI：`http://localhost:8080/swagger-ui.html`
- OpenAPI：`http://localhost:8080/v3/api-docs`

## 后端环境变量

| 变量 | 作用 | 默认/说明 |
| --- | --- | --- |
| `MYSQL_HOST` | MySQL 地址 | `localhost` |
| `MYSQL_PORT` | MySQL 端口 | `3306` |
| `MYSQL_DB` | 数据库名 | `zhaobiao_admin` |
| `MYSQL_USER` | 数据库用户 | 本地默认 `root`，生产禁止 root |
| `MYSQL_PASSWORD` | 数据库密码 | 本地默认 `root`，生产禁止 root 密码 |
| `APP_JWT_SECRET` | JWT 签名密钥 | 必须配置，至少 32 字符 |
| `APP_BOOTSTRAP_ADMIN_PASSWORD` | 初始化 admin 密码 | 只有 DataInitializer 被注册时才使用 |
| `SPRING_PROFILES_ACTIVE` | Spring Profile | `prod` 会启用数据库安全校验 |
| `APP_FILE_TYPE` | 文件存储类型 | `local` 或 `oss` |
| `APP_FILE_STORAGE_PATH` | 本地文件目录 | `./.uploads/files` |
| `APP_FILE_TEMP_PATH` | 本地临时目录 | `./.uploads/tmp` |
| `APP_FILE_OSS_BUCKET` | OSS bucket | OSS 模式必填 |
| `APP_FILE_OSS_ENDPOINT` | OSS endpoint | OSS 模式必填，可不带 scheme |
| `APP_FILE_OSS_CREDENTIAL_MODE` | OSS 凭证模式 | `access-key` 或 `ecs-ram-role` |
| `APP_FILE_OSS_ROLE_NAME` | ECS RAM Role 名称 | `ecs-ram-role` 模式必填 |
| `APP_FILE_OSS_ACCESS_KEY_ID` | OSS AK | `access-key` 模式必填 |
| `APP_FILE_OSS_ACCESS_KEY_SECRET` | OSS SK | `access-key` 模式必填 |
| `APP_FILE_OSS_KEY_PREFIX` | OSS object key 前缀 | `zb/files` |

## 本地前端启动

后台管理端：

```bash
cd frontend
npm install
npm run dev
```

门户端：

```bash
cd front
npm install
npm run dev
```

开发代理：

- 后台默认把 `/api/*` 代理到 `https://xiazhiyong.vip`，可用 `VUE_APP_PROXY_TARGET` 改为本地后端。
- 门户默认把 `/api/*` 代理到 `https://xiazhiyong.vip`，可用 `VITE_PROXY_TARGET` 改为本地后端。

## 生产部署形态

当前已知生产形态：

- 后端：Spring Boot jar，由 systemd 管理。
- 后台管理端：Nginx 静态目录，对外路径 `/ztbgl/`。
- 会员门户端：Nginx 静态目录，对外路径 `/ztbfb/`。
- 数据库：MySQL。
- 文件：本地或 Aliyun OSS，生产常见为 OSS。

生产注意：

- 不要依赖旧 PID 文件判断服务状态。
- 不要把 `app.env`、密码、AccessKey、JWT secret 写入仓库文档。
- 升级 jar 版本后，要确认 systemd `ExecStart` 指向新 jar。
- 生产 DB 变更必须走 SQL 脚本，不能只依赖 Hibernate 自动更新。

## 生产服务检查 SOP

在服务器上检查：

```bash
systemctl list-units --type=service --all | grep -i zhaobiao
systemctl status zhaobiao-admin
ss -ltnp | grep ':8080'
curl -I http://127.0.0.1:8080/swagger-ui.html
curl -I http://127.0.0.1:8080/v3/api-docs
```

预期：

- 只有一个 systemd 管理的后端进程占用 8080。
- Swagger UI 返回 302 或 200。
- `/v3/api-docs` 可访问。

## 空库初始化

当前 `DataInitializer` 没有在主应用中自动注册为 Spring Bean。空库准备要二选一：

1. 执行 `sql/mysql8/data-initializer.sql`。
2. 明确把 `DataInitializer` 注册进启动流程，并配置 `APP_BOOTSTRAP_ADMIN_PASSWORD`。

不要假设空库启动后自动拥有：

- `admin` 账号。
- 菜单。
- 角色。
- 业务类型。

## 生产安全启动校验

`SPRING_PROFILES_ACTIVE=prod` 时，`ProductionDatabaseSecurityValidator` 会阻止：

- 数据库用户名为空。
- 数据库密码为空。
- 数据库用户名为 `root`。
- 数据库密码为 `root`。

这类错误是安全保护，不应通过放宽代码绕过。
