# 快速开发与验证指南

## 开始前先看

1. 确认要改后端、后台管理端还是门户端。
2. 搜索现有 Controller、Service、Entity、DTO 和测试。
3. 确认是否涉及权限、菜单、SQL、前端按钮或文档联动。
4. 不要改无关文件，不做顺手重构。

## 常用搜索

```bash
rg -n "TENDER_PUBLISH_BUTTON|NEWS_PUBLISH_BUTTON|MEMBER_DOWNLOAD_BUTTON" src frontend front sql docs
rg -n "@RequestMapping|@GetMapping|@PostMapping|@PutMapping|@DeleteMapping|@PreAuthorize" src/main/java/com/zhaobiao/admin/controller
rg -n "@Entity|@Table|enum" src/main/java/com/zhaobiao/admin/entity
rg -n "listPortalTenders|getPortalTenderDetail|portalRegister|uploadAdminFiles" frontend front
```

## 后端本地验证

运行全部测试：

```bash
mvn test
```

打包：

```bash
mvn clean package -DskipTests
```

注意：

- 测试需要本地 MySQL 8，可通过 Docker 提供。
- 测试配置默认库是 `zhaobiao_admin_test`。
- 文件测试会写入 `.test-uploads/`。

## 前端验证

后台管理端：

```bash
cd frontend
npm run build:prod
```

门户端：

```bash
cd front
npm run build
```

如果只是文档变更，不需要构建前端；但要检查文档里路径、命令和业务口径是否过期。

## 改权限能力的联动清单

新增或改后台按钮能力时，至少检查：

- Controller `@PreAuthorize`。
- `DataInitializer` 菜单按钮种子。
- `sql/mysql8/data-initializer.sql`。
- 生产增量 SQL。
- 后台页面 `v-auth`。
- `RoleService` 是否仍只用 `menuIds`。
- 集成测试是否覆盖有权限/无权限。
- `docs/知识文档/00-核心业务/账号权限与后台管理.md` 和接口清单。

## 改招标逻辑的联动清单

至少检查：

- `TenderAdminController`。
- `TenderService`。
- `PortalTenderController`。
- `PortalTenderService`。
- `TenderRepository` 查询。
- `TenderIntegrationTests`。
- 后台招标页面。
- 门户列表/详情/下载页面。
- SQL 是否需要变更。

## 改会员逻辑的联动清单

至少检查：

- `MemberAdminController`。
- `MemberAdminService`。
- `PortalAuthController`。
- `PortalAuthService`。
- `MemberUserDetailsService`。
- `MemberUserRepository`。
- `AuthFlowIntegrationTests`。
- 后台会员页面。
- 门户登录、注册、账户设置页面。

## 改文件逻辑的联动清单

至少检查：

- `FileAdminController`。
- `FileThumbnailController`。
- `LocalFileStorageService`。
- `OssFileStorageService`。
- `FileThumbnailGenerator`。
- `TenderService.cleanupUnreferencedFiles`。
- `FileThumbnailIntegrationTests`。
- `TenderIntegrationTests` 中下载和文件引用清理场景。

## 生产变更前检查

- 是否新增 SQL 脚本。
- 是否更新 `docs/production-db-schema-change-list.md` 或本知识文档。
- 是否确认线上真实 service 名、jar 路径、端口、Nginx 路径。
- 是否避免输出或提交任何密钥。
- 是否准备回滚方式。
