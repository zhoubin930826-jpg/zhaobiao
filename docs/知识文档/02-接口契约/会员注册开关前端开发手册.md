# 会员注册开关前端开发手册

日期：2026-06-19

## 业务结论

客户需要后台不定期关闭或开启门户会员自助注册。后端已经提供注册开关，默认开启；关闭后门户前端应隐藏注册入口，用户即使直接进入注册页并提交，后端也会返回业务码 `403`，不会创建会员。

关闭注册只影响门户自助注册：

- 不影响后台管理员创建会员。
- 不影响已有会员登录。
- 不影响会员资料维护、改密、招标查看和附件下载。
- 不影响注册验证码图片接口本身；真正拦截点是 `POST /api/portal/auth/register`。

## 后台管理端改动

页面建议：`frontend/src/pages/sys/member/index.vue`，放在会员管理页顶部工具栏，和“新增会员”等操作同一层级。

权限码：

| 功能 | 权限码 |
| --- | --- |
| 查询注册开关 | `SYSTEM_MEMBER_USER` |
| 修改注册开关 | `MEMBER_REGISTRATION_SETTING_BUTTON` |

接口：

```http
GET /api/admin/members/registration-setting
Authorization: Bearer <admin-token>
```

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "registrationEnabled": true
  }
}
```

```http
PUT /api/admin/members/registration-setting
Authorization: Bearer <admin-token>
Content-Type: application/json

{
  "registrationEnabled": false
}
```

成功响应同上，`registrationEnabled` 是更新后的状态。

失败处理：

- 无修改权限：HTTP 通常仍是 `200`，响应 `code=403`。
- 未传 `registrationEnabled`：响应 `code=400`，提示“是否开启会员注册不能为空”。
- 前端必须判断响应体 `code`，不能只看 HTTP 状态。

推荐 UI：

- 使用 `i-switch` 或等价开关控件。
- 文案建议：
  - 开启：`允许门户注册`
  - 关闭：`已关闭门户注册`
- 关闭操作建议弹确认框：`关闭后，门户访客将看不到注册入口，直接提交注册也会失败。确认关闭？`
- 只有拥有 `MEMBER_REGISTRATION_SETTING_BUTTON` 时显示可操作开关；只有 `SYSTEM_MEMBER_USER` 但没有按钮权限时，可展示只读状态或直接不展示开关。

后台请求封装示例：

```js
export function getMemberRegistrationSetting() {
  return request({
    url: '/admin/members/registration-setting',
    method: 'get'
  })
}

export function updateMemberRegistrationSetting(registrationEnabled) {
  return request({
    url: '/admin/members/registration-setting',
    method: 'put',
    data: { registrationEnabled }
  })
}
```

## 门户端改动

页面建议：

- `front/src/views/LoginView.vue`：决定是否显示“注册”入口。
- `front/src/views/RegisterView.vue`：进入页面时再次查询开关，关闭时展示不可注册状态并禁用提交。
- 路由守卫可选：访问 `/register` 前查询开关，关闭时重定向到 `/login` 或展示提示页。

公开接口：

```http
GET /api/portal/auth/registration-status
```

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "registrationEnabled": false
  }
}
```

门户请求封装示例：

```js
export function getRegistrationStatus() {
  return request({
    url: '/portal/auth/registration-status',
    method: 'get'
  })
}
```

门户行为建议：

1. 登录页加载时调用 `GET /api/portal/auth/registration-status`。
2. `registrationEnabled=true` 时显示注册入口。
3. `registrationEnabled=false` 时隐藏注册入口。
4. 注册页加载时也调用一次，防止用户直接输入 `/register`。
5. 注册提交如果收到 `code=403` 和“会员注册已关闭，请联系管理员”，清空验证码并提示用户。

注册接口保持不变：

```http
POST /api/portal/auth/register
Content-Type: multipart/form-data
```

关闭时失败响应：

```json
{
  "code": 403,
  "message": "会员注册已关闭，请联系管理员",
  "data": null
}
```

## 状态同步建议

- 不建议把注册开关永久缓存在 localStorage；后台可能临时开启/关闭。
- 登录页每次进入都查询一次即可。
- 注册页提交前不必额外再查一次，因为后端注册接口会强制校验；但页面初始化时查一次可以改善体验。
- 如果后台切换开关后门户页面已打开，用户仍可能看到旧状态。以提交注册时后端返回为准。

## 前端验收点

- 后台有权限管理员可以看到当前状态，并能开启/关闭。
- 没有 `MEMBER_REGISTRATION_SETTING_BUTTON` 的管理员不能修改。
- 门户关闭状态下登录页不显示注册入口。
- 直接访问 `/register` 时不能提交注册。
- 后台重新开启后，门户刷新页面能看到注册入口，注册流程恢复为原逻辑。
