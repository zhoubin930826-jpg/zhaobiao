## 当前系统一句话

这是一个招标信息管理与门户公示系统：后台管理员维护管理员、会员、业务类型、招标、资讯、角色菜单和操作日志；门户访客可看公开招标和资讯，会员登录后可看授权业务类型下的招标列表，并在满足下载权限时下载附件。

## 维护原则

- 代码、配置、SQL 和真实运行环境优先于历史文档。
- 修改业务规则时，同步更新本目录对应的业务文档、接口清单、数据字典和测试用例说明。
- 修改权限、菜单、角色时，同步检查 Controller `@PreAuthorize`、`DataInitializer`、`sql/mysql8/data-initializer.sql`、生产迁移脚本和前端按钮显示。
- 修改门户可见性或下载逻辑时，必须覆盖游客、有效会员、禁用会员、过期会员、无业务类型会员、无下载权限会员。
