# 术语表

| 术语 | 含义 | 代码/数据来源 |
| --- | --- | --- |
| 后台管理端 | 管理员使用的 Vue 2 管理后台，生产路径 `/ztbgl/` | `frontend/` |
| 会员门户端 | 游客和会员访问的 Vue 3 门户，生产路径 `/ztbfb/` | `front/` |
| 管理员账号 | 后台登录账号，存储于 `sys_user`，通过角色获得后台菜单和按钮 | `User`, `AdminAccountService` |
| 会员账号 | 门户登录账号，存储于 `portal_member_user`，通过业务类型和下载权限控制可见/可下载范围 | `MemberUser`, `PortalAuthService` |
| 业务类型 | 招标和会员之间的分类授权维度，默认工程、货物、服务，可后台维护 | `biz_business_type` |
| 菜单 | 后台可见页面节点，`sys_menu.type=MENU` 或 `DIRECTORY` | `Menu`, `DataInitializer` |
| 按钮权限 | 后台操作能力节点，`sys_menu.type=BUTTON`；授权编码就是菜单 `code` | `RoleService`, `LoginUser` |
| 角色 | 一组菜单/按钮节点，管理员账号通过角色获得权限 | `sys_role`, `sys_role_menu` |
| SUPER_ADMIN | 超级管理员角色，拥有所有启用菜单和按钮；初始 `admin` 必须保留 | `SystemConstants`, `AdminAccountService` |
| SYSTEM_ADMIN | 系统管理员角色，拥有大部分业务管理能力，但不管理管理员账号 | `DataInitializer` |
| NORMAL_USER | 历史普通用户角色，不应分配给管理员账号 | `SystemConstants`, `AdminAccountService` |
| 招标 | 后台维护的招标公告，门户展示给游客/会员 | `biz_tender` |
| 招标附件 | 招标绑定的文件记录，下载受会员状态、业务类型、下载权限控制 | `biz_tender_attachment`, `PortalTenderService` |
| 资讯 | 后台维护、门户公开展示的新闻/公告/指南/法规 | `biz_news` |
| DRAFT | 草稿状态；可编辑、可删除，未公开展示 | `TenderStatus`, `NewsStatus` |
| PUBLISHED | 已发布状态；门户在 `publishAt <= now` 时公开展示；后台不能直接编辑/删除 | `TenderService`, `NewsService` |
| CLOSED | 招标枚举中保留状态；当前发布状态接口不允许设置为 `CLOSED` | `TenderStatus`, `TenderService` |
| publishAt | 发布时间；门户只展示 `publishAt` 不晚于当前时间的数据 | `TenderRepository`, `NewsRepository` |
| expiresAt | 会员过期时间；为空或不晚于当前时间视为过期，不能登录 | `PortalAuthService` |
| canDownloadFile | 会员是否允许下载附件；即使能看详情，没有该权限也不能下载 | `MemberUser`, `PortalTenderService` |
| profileCompletionRequired | 会员首次成功登录时返回 true，提示前端引导完善资料 | `PortalAuthService` |
| 缩略图 | 文件上传时或首次访问时生成的 JPEG 缩略图；图片/PDF 为真实缩略图，其他类型为文件类型封面 | `FileThumbnailGenerator` |
| ApiResponse | 后端统一响应；业务失败通常仍是 HTTP 200，但 `code` 非 0 | `ApiResponse`, `GlobalExceptionHandler` |
| 410 | 旧接口或已停用能力的业务码，例如旧 `/api/admin/users`、权限管理接口 | `AdminUserController`, `PermissionController` |
