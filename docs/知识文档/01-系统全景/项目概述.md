# 项目概述

## 系统定位

招标系统服务于“后台维护招标与资讯、门户展示招标与资讯、会员受控下载附件”的业务场景。

系统不是单一前端项目，而是三块共同组成：

| 部分 | 目录 | 技术栈 | 负责能力 |
| --- | --- | --- | --- |
| 后端服务 | `src/main/java/com/zhaobiao/admin` | Java 8、Spring Boot 2.7.18、Spring Security、JPA、MySQL、JWT | 认证、权限、业务规则、文件存储、接口 |
| 后台管理端 | `frontend/` | Vue 2.6、Vue CLI 3、View Design/iView 风格模板 | 管理员登录、账号、会员、业务类型、招标、资讯、角色菜单、日志 |
| 会员门户端 | `front/` | Vue 3.2、Vite 2 | 游客/会员查看招标、资讯、注册登录、资料维护、附件下载 |

## 使用角色

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 游客 | 访问门户；查看最新 3 条已发布且已到发布时间的招标；查看公开招标详情正文；查看门户资讯 | 不能进入会员列表接口；不能下载招标附件；不能访问后台管理 |
| 会员 | 登录门户；查看自己业务类型范围内的招标列表；查看公开招标详情；满足权限时下载附件；维护个人资料文件 | 不能访问后台；不能越过业务类型和下载权限下载附件 |
| 系统管理员 | 维护会员、业务类型、招标、资讯、角色、菜单和日志 | 默认不能管理其他管理员账号 |
| 超级管理员 | 拥有后台全部启用菜单和按钮；管理管理员账号 | 初始 `admin` 不能被禁用，且必须保留超级管理员角色 |
| 新增/编辑型业务管理员 | 可以维护草稿招标或草稿资讯 | 没有发布按钮权限时不能发布或下架 |

## 业务模块地图

| 模块 | 后端入口 | 服务层 | 主要数据表 |
| --- | --- | --- | --- |
| 后台认证 | `AuthController` | `AuthService` | `sys_user`, `sys_user_role`, `sys_role`, `sys_menu` |
| 管理员账号 | `AdminAccountController` | `AdminAccountService` | `sys_user`, `sys_user_role`, `sys_role` |

| 招标管理 | `TenderAdminController`, `PortalTenderController` | `TenderService`, `PortalTenderService` | `biz_tender`, `biz_tender_attachment`, `biz_file_storage` |

| 文件 | `FileAdminController`, `FileThumbnailController` | `LocalFileStorageService`, `OssFileStorageService`, `FileThumbnailGenerator` | `biz_file_storage` |

| 操作日志 | `OperationLogController` | `OperationLogService`, `OperationLogAspect` | `sys_operation_log` |

## 当前代码与历史口径差异

| 主题 | 历史笔记口径 | 当前代码/AGENTS 口径 | 文档采用 |
| --- | --- | --- | --- |
| 门户注册 | 旧 Obsidian 笔记写过“公开注册不开放” | `PortalAuthController` 已开放 `/api/portal/auth/register`，注册后会员为 `DISABLED`，需后台分配业务类型、过期时间并启用 | 采用当前代码 |
| 权限配置 | 早期有独立 `sys_permission` 和权限管理页 | 当前权限心智收敛为“角色绑定菜单/按钮，菜单 code 即授权编码”，旧权限接口返回 410 | 采用当前代码 |
| 招标/资讯发布 | 早期创建时可直接设置状态 | 当前创建固定 `DRAFT`，发布/下架必须走 status 接口并有发布按钮权限 | 采用当前代码 |
