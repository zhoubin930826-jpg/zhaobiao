## 分层策略

| 层 | 目标 | 命令/方式 |
| --- | --- | --- |
| 单元/组件 | 配置、安全校验、OSS 凭证等局部逻辑 | JUnit |
| 集成接口 | MockMvc 覆盖 Controller-Service-Repository-DB | `mvn test` |
| 前端构建 | 验证路由、语法、构建配置 | `npm run build:prod`、`npm run build` |
| 手工验收 | 验证真实页面联动、权限按钮、下载行为 | 本地或测试环境浏览器 |
| 生产验证 | 验证真实服务、数据库和 Nginx | systemd、curl、日志 |

## 核心业务用例

### 管理员账号

- 超级管理员能创建管理员。
- 非超级管理员不能访问 `/api/admin/admin-users`。
- 管理员不能分配 `NORMAL_USER`。
- 初始 `admin` 不能禁用。
- 初始 `admin` 不能移除 `SUPER_ADMIN`。
- 旧 `/api/admin/users` 返回 410。

### 会员

- 门户注册必须校验验证码。
- 门户注册必须上传两类资料文件。
- 注册后会员为 `DISABLED`，不能直接登录。
- 后台创建会员必须有业务类型和过期时间。
- 启用会员时缺业务类型或过期时间失败。
- 过期会员不能登录。
- 首次登录返回 `profileCompletionRequired=true`，第二次为 false。
- 禁用会员不能继续用旧 token 访问受保护接口。
- 软删除会员后不在后台列表，不能登录。
- 会员自助修改密码必须校验旧密码；成功后旧密码登录失败、新密码登录成功。

### 招标

- 新增招标固定 `DRAFT`。
- 创建/编辑校验项目编号唯一、发布时间、报名截止时间。
- 无发布权限不能发布。
- 发布后门户在 `publishAt <= now` 时可见。
- 已发布招标不能编辑、删除、增删附件。
- 游客最新列表最多 3 条。
- 会员列表按业务类型过滤。
- 游客详情可看正文但不能下载附件。
- 会员附件下载要求业务类型匹配和 `canDownloadFile=true`。

### 资讯

- 新增资讯固定 `DRAFT`。
- 无发布权限不能发布。
- 已发布资讯不能编辑和删除。
- 门户只展示已发布且发布时间已到的资讯。
- 草稿或未来发布时间详情返回 404。

### 文件

- 上传空文件失败。
- 相同内容文件去重。
- 图片/PDF 有可用缩略图。
- 非图片/PDF 返回类型封面和 `UNSUPPORTED`。
- 后台下载和 inline 查看都需要权限。
- 删除招标附件时不能误删仍被会员资料或资讯封面引用的文件。

## 手工验收流程

后台验收：

1. 登录超级管理员。
2. 检查菜单是否完整。
3. 新增业务类型。
4. 新增会员，设置业务类型、过期时间、下载权限。
5. 新增招标草稿，上传附件。
6. 使用无发布权限角色确认看不到发布按钮或发布接口 403。
7. 使用有发布权限角色发布招标。
8. 发布后确认编辑、删除、附件增删被拒绝。
9. 新增资讯草稿，发布后在门户可见。

门户验收：

1. 未登录打开 `/list`，只看到最新公开招标。
2. 未登录打开招标详情，能看正文，下载提示登录。
3. 注册会员，确认后台显示 DISABLED。
4. 后台启用会员并分配业务类型。
5. 登录门户，首次登录跳到账户设置。
6. 查看会员列表，只出现授权业务类型的招标。
7. 开启下载权限后下载附件成功。
8. 修改会员自己的密码，确认旧密码失效、新密码可登录。
9. 禁用或过期会员后，登录和受保护请求失败。

## 文档变更验证

文档类变更通常不需要跑全量测试，但至少做：

```bash
find docs/知识文档 -type f | sort
git diff -- docs/知识文档
```

如果文档中描述了新业务行为，必须用当前代码或测试证明，不要只从历史笔记复制。
