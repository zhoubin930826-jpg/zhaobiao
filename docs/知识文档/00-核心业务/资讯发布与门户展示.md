# 资讯发布与门户展示

## 业务目标

资讯模块用于后台维护平台公告、行业动态、办事指南和政策法规，并在门户公开展示。它和招标一样采用“草稿维护、单独发布”的发布审核边界。

## 分类和状态

资讯分类：

| 枚举 | 展示名称 |
| --- | --- |
| `PLATFORM_NOTICE` | 平台公告 |
| `INDUSTRY_NEWS` | 行业动态 |
| `SERVICE_GUIDE` | 办事指南 |
| `POLICY_REGULATION` | 政策法规 |

资讯状态：

| 状态 | 含义 | 能否门户展示 | 能否编辑/删除 |
| --- | --- | --- | --- |
| `DRAFT` | 草稿 | 不能 | 能 |
| `PUBLISHED` | 已发布 | `publishAt <= now` 时能 | 不能，需先下架为 `DRAFT` |

## 后台维护流程

新增资讯：

1. 进入后台“资讯管理”。
2. 填写标题、分类、来源、摘要、正文、发布时间。
3. 可上传封面文件，封面实际是 `biz_file_storage` 的文件 ID。
4. 提交 `POST /api/admin/news`。
5. 后端固定保存为 `DRAFT`。

编辑资讯：

1. 只能编辑 `DRAFT`。
2. 请求体不能改变状态。
3. 如果要改已发布资讯，先通过状态接口改回 `DRAFT`。

发布/下架：

```text
PUT /api/admin/news/{newsId}/status
Body: { "status": "PUBLISHED" } 或 { "status": "DRAFT" }
权限: NEWS_PUBLISH_BUTTON
```

删除：

- 需要 `NEWS_DELETE_BUTTON`。
- 只允许删除 `DRAFT`。
- 当前删除资讯不会直接删除封面文件记录；文件清理逻辑会在招标附件清理时考虑资讯封面引用，避免误删仍被资讯使用的文件。

## 门户展示流程

门户接口全部公开，不要求会员 token：

| 场景 | 接口 | 规则 |
| --- | --- | --- |
| 分页列表 | `GET /api/portal/news` | 只返回 `PUBLISHED` 且 `publishAt <= now`，支持 `keyword`、`category` |
| 最新资讯 | `GET /api/portal/news/latest?limit=6` | limit 默认 6，最大 20 |
| 资讯详情 | `GET /api/portal/news/{newsId}` | 草稿、未来发布时间或不存在均返回业务码 404 |

门户首页和列表页会把 `coverUrl` 转成可访问 URL。封面 URL 来自公开缩略图接口 `/api/files/{fileId}/thumbnail`。

## 发布权限拆分

发布能力必须与新增/编辑拆开：

| 权限 | 能力 |
| --- | --- |
| `SYSTEM_NEWS` | 查看资讯列表和详情 |
| `NEWS_CREATE_BUTTON` | 新增草稿资讯 |
| `NEWS_EDIT_BUTTON` | 编辑草稿资讯 |
| `NEWS_DELETE_BUTTON` | 删除草稿资讯 |
| `NEWS_PUBLISH_BUTTON` | 发布和下架 |
| `NEWS_UPLOAD_BUTTON` | 上传封面 |

前端按钮显示：

- 草稿行：可显示编辑、发布、删除。
- 已发布行：只显示取消发布。
- 前端 `canPublish` 来自当前用户权限是否包含 `NEWS_PUBLISH_BUTTON`。

## 测试关注点

- 新增资讯固定为 `DRAFT`。
- 无发布权限不能发布或下架。
- 已发布资讯拒绝编辑、删除。
- 门户列表、最新和详情只暴露已发布且发布时间已到的数据。
- 草稿和未来发布时间资讯在门户详情返回 404。
