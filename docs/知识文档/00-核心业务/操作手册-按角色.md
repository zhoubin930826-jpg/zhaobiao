# 操作手册-按角色

## 管理员第一次接手系统

1. 打开后台管理端 `/ztbgl/`。
2. 使用管理员账号登录。后端接口是 `POST /api/auth/login`。
3. 登录成功后前端读取 `GET /api/auth/me` 返回的 `menus` 和 `permissions`。
4. 左侧菜单来自后台返回的菜单树，不是前端写死；如果菜单缺失，先查角色是否绑定菜单/按钮。
5. 进入业务模块前，先确认当前账号是否有对应菜单和按钮 code。

常见按钮 code：

| 能力 | 按钮 code |
| --- | --- |
| 新增会员 | `MEMBER_CREATE_BUTTON` |
| 编辑会员 | `MEMBER_EDIT_BUTTON` |
| 设置会员下载权限 | `MEMBER_DOWNLOAD_BUTTON` |
| 启用/禁用会员 | `MEMBER_STATUS_BUTTON` |
| 重置会员密码 | `MEMBER_PASSWORD_BUTTON` |
| 删除会员 | `MEMBER_DELETE_BUTTON` |
| 新增招标 | `TENDER_CREATE_BUTTON` |
| 编辑招标/维护附件 | `TENDER_EDIT_BUTTON` |
| 发布/改为未发布招标 | `TENDER_PUBLISH_BUTTON` |
| 删除招标 | `TENDER_DELETE_BUTTON` |
| 新增资讯 | `NEWS_CREATE_BUTTON` |
| 编辑资讯 | `NEWS_EDIT_BUTTON` |
| 发布/下架资讯 | `NEWS_PUBLISH_BUTTON` |
| 删除资讯 | `NEWS_DELETE_BUTTON` |

## 超级管理员管理后台账号

适用角色：拥有 `SUPER_ADMIN` 的管理员。

操作流程：

1. 进入“管理员管理”。
2. 新增管理员账号，填写用户名、手机号、邮箱、真实姓名、密码和角色。
3. 角色不能选择 `NORMAL_USER`，否则后端拒绝。
4. 修改管理员角色时，初始 `admin` 必须保留 `SUPER_ADMIN`。
5. 修改管理员状态时，只允许 `APPROVED` 或 `DISABLED`；初始 `admin` 不能被禁用。
6. 重置密码只改变密码，不改变角色和状态。

联动规则：

- 管理员账号存储在 `sys_user`。
- 账号可见能力来自 `sys_user_role -> sys_role_menu -> sys_menu.code`。
- 只有 `SUPER_ADMIN` 可以访问 `/api/admin/admin-users`。
- 旧 `/api/admin/users` 已停用，返回业务码 410，不能作为管理员管理入口。

## 系统管理员配置业务类型

操作流程：

1. 进入“类型管理”。
2. 新增类型时填写编码、名称、启用状态、排序和描述。
3. 编码会被后端转为大写；编码和名称必须唯一。
4. 禁用类型后，不能再被新招标或会员绑定使用。
5. 删除类型前必须确认没有会员和招标引用；有引用时只能停用，不能删除。

业务影响：

- 会员可见的招标列表依赖会员绑定的业务类型。
- 招标必须绑定一个启用中的业务类型。
- 改业务类型会影响门户筛选和会员授权范围。

## 后台创建或启用会员

后台创建会员流程：

1. 进入“会员管理”。
2. 新增会员，填写用户名、手机号、邮箱、公司、联系人、统一社会信用代码、密码。
3. 至少选择一个启用中的业务类型。
4. 必须设置会员过期时间 `expiresAt`。
5. 可选择是否允许下载附件 `canDownloadFile`。
6. 可上传营业执照和近三年业绩文件，文件上传后只把 fileId 绑定到会员。
7. 保存成功后，会员可按状态登录门户。

门户自注册后的启用流程：

1. 会员在门户注册，必须上传营业执照和近三年业绩证明。
2. 后端创建会员为 `DISABLED`、无业务类型、无过期时间、`canDownloadFile=false`。
3. 管理员在后台补充业务类型、过期时间。
4. 管理员把状态改为 `ENABLED`。
5. 需要下载附件时，再开启 `canDownloadFile`。

启用校验：

- 启用会员前必须至少有一个业务类型。
- 启用会员前必须有过期时间。
- 会员过期后不能登录；旧 token 也会在用户详情加载阶段失效。

## 招标管理员发布招标

草稿维护流程：

1. 进入“招标管理”。
2. 新增招标，填写标题、地区、业务类型、发布时间、正文、联系人、预算、联系电话、招标单位、项目截止时间、项目编号、报名截止时间。
3. 新增时后端固定保存为 `DRAFT`，即使请求里传了状态也不能绕过发布流程。
4. 上传附件，后端返回 fileId、文件名、大小、缩略图地址。
5. 附件绑定到招标，按传入顺序保存排序。
6. 草稿可编辑、删除、增删附件。

发布流程：

1. 只有有 `TENDER_PUBLISH_BUTTON` 的账号能发布。
2. 点击发布时调用 `PUT /api/admin/tenders/{tenderId}/status`，状态传 `PUBLISHED`。
3. 已发布后，后台不能直接编辑、删除或增删附件。
4. 要改已发布招标，必须先由有发布权限的人改回 `DRAFT`。
5. 门户只展示 `PUBLISHED` 且 `publishAt <= 当前时间` 的招标。

时间规则：

- 报名截止时间不能晚于项目截止时间。
- 发布时间不能晚于项目截止时间。
- 门户是否可见取决于状态和发布时间，不取决于创建时间。

## 资讯管理员发布资讯

草稿维护流程：

1. 进入“资讯管理”。
2. 新增资讯，填写标题、分类、来源、摘要、正文、发布时间，可上传封面。
3. 新增时固定为 `DRAFT`。
4. 草稿可编辑、删除。

发布流程：

1. 只有 `NEWS_PUBLISH_BUTTON` 能发布或下架。
2. 发布调用 `PUT /api/admin/news/{newsId}/status`，状态传 `PUBLISHED`。
3. 已发布资讯不能直接编辑或删除，必须先下架为 `DRAFT`。
4. 门户只展示 `PUBLISHED` 且 `publishAt <= 当前时间` 的资讯。

## 门户游客使用系统

游客可以：

- 打开门户 `/ztbfb/`。
- 查看最新 3 条公开招标，接口为 `GET /api/portal/tenders/latest`。
- 查看已发布且发布时间已到的招标详情，接口为 `GET /api/portal/tenders/{tenderId}`。
- 查看资讯列表、最新资讯和资讯详情。
- 注册会员账号。

游客不能：

- 调用会员招标分页列表 `GET /api/portal/tenders`。
- 下载附件。
- 访问账户设置页。

## 门户会员使用系统

登录流程：

1. 打开登录页。
2. 拉取验证码图片 `GET /api/portal/auth/captcha?scene=login&captchaId=...`。
3. 提交用户名、密码、captchaId、captchaCode。
4. 后端校验账号存在、密码正确、状态启用、未过期、已分配启用业务类型。
5. 首次成功登录时写入 `firstLoginAt`，返回 `profileCompletionRequired=true`。
6. 前端保存 token 到 `localStorage` 的 `zb_portal_auth`。

会员看招标：

- 登录后列表页调用 `GET /api/portal/tenders`，只返回会员业务类型范围内的招标。
- 分类页通过 `businessTypeName` 过滤，但仍不能越过会员已分配业务类型。
- 详情页可打开任何已发布且发布时间已到的招标正文；真正严格保护的是附件下载。

会员下载附件：

1. 详情接口返回 `canDownload`。
2. 前端以 `canDownload` 控制下载按钮。
3. 点击下载调用 `GET /api/portal/tenders/{tenderId}/attachments/{attachmentId}/download`，必须带会员 token。
4. 后端再次校验会员业务类型、下载权限和附件归属。

会员修改自己的密码：

1. 会员必须先登录门户，携带会员 token。
2. 调用 `PUT /api/portal/auth/password`。
3. 请求体包含 `oldPassword`、`password`、`confirmPassword`。
4. 后端校验旧密码正确、新密码 6-32 位且两次一致。
5. 修改成功后，旧密码不能再登录，新密码可以登录。
